# Боб × ASDASD

Интерактивный прототип маскота на копии главной страницы ASDASD Agency.
Демонстрация для обсуждения с командой агентства. Оригинальные дизайн и персонаж принадлежат их авторам.

Боб гуляет по нижнему краю страницы, следит глазами за курсором, реагирует на проекты и кнопки.
Нажмите на Боба для вопросов; зажмите и перетащите, чтобы поднять и бросить.
В панели «Проба Боба» можно остановить прогулку, скрыть персонажа или вернуть его на место.
Ссылки на другие страницы открывают действующий сайт агентства.

Статический сайт: HTML, CSS, JavaScript и ассеты, без установки зависимостей и серверной части.
GitHub Pages: branch `main`, folder `/ (root)`. `.nojekyll` сохраняет папку `_next`.
